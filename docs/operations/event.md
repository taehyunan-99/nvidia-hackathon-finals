# 본선 안내와 확인할 조건

기준: **2026-10-07**. 기존 본선 안내 메일에 오늘의 슬랙 공지·발표자료·챌린지 저장소를 반영했다. 미션·공식 배점·제출물·출처 차이의 원본은 [본선 미션과 제출 요건](mission.md)이다.

## 최신 미션·제출 조건

- 한국 문화·역사·지역·여행의 맥락과 자료 신뢰성을 판단해 실제 사용할 결과를 만드는 에이전트가 미션이다. **OpenShell 포함과 동작하는 데모는 필수**다.
- 제공 `/hackathon/input`을 활용하고 `/hackathon/output`에 결과를 만든다. `/hackathon/restricted`와 `/hackathon/secrets`는 접근 금지다. 발표 중 추가 요청·예외 조건이 주어질 수 있다.
- **17:20까지** 발표자료·데모코드를 제출한다. 저장소 README는 지정 Slack 제출 채널에 팀명·프로젝트명·저장소·데모 URL 또는 실행 방법·발표자료를 함께 제출하도록 안내한다.
- 공식 배점은 NVIDIA 기술 40, 실용성·가치·혁신 20, 완성도 20, 발표 10, 동료평가 10이다. 동료평가 세부 산식의 자료 간 차이는 [미션 문서](mission.md#10-자료-간-차이와-미확인-사항)에 남겼다.

기술 구현은 [OpenShell 보안정책 분석](../catalog/tools/openshell-security.md)과 [배포 준비](../playbooks/openshell-deployment.md)를 사용한다. 공통 연습 파일은 제품 주제의 한계가 아니다.

## 공개 자료와 구분

[공식 행사 페이지](https://fastcampus.co.kr/NVIDIA_hackathon)의 2026-10-03 조사에서는 상세 배점을 확인하지 못했으나, **10월 7일 슬랙과 발표 PDF에서 공식 배점이 제공됐다.** 이전 미확정 기록으로 최신 공지를 무시하지 않는다.

PDF p.3은 오늘 선발 10팀의 오프라인 행사와 11월 9–10일 AI Day Seoul의 Top 5팀 쇼케이스를 설명한다. 오늘 평가 대상과 11월 발표 주제에 대한 구두 보충은 [미션 범위](mission.md#3-행사와-평가-대상의-범위)에서 구분한다.

PDF p.13의 현재 지원은 **팀당 약 $500 Brev 크레딧**, L40S 권장·팀별 자원 자유 선택이다. 이 대화에서도 코드 등록 후 $500 잔액을 콘솔에서 확인했다. 예선의 L40S 1대·최대 $1,000 안내를 오늘의 보장 자원으로 재사용하지 않는다. 크레딧 만료·가용 인스턴스·실제 요금과 모델 API 한도는 별도 확인한다.

## 현장 소통과 지원

PDF p.17은 전체 소통에 Slack의 `#fastcampus-agentic-ai-hackathon` 채널을 사용하고, NVIDIA 기술 문의는 **13층 회의실 A/B**에 방문하도록 안내한다. 최종 제출 채널이 이 공지 채널과 같은지는 실제 운영 공지에서 확인한다.
