# 본선 안내와 확인할 조건

기준: 2026-10-03. 일정의 1차 근거는 사용자가 이 대화에 전달한 패스트캠퍼스 본선 진출 안내 메일이다.

## 확정 안내

- 2026-10-07 수요일 09:00–19:00, 한국 시간.
- 서울 서대문구 연세로 8-1 버티고타워 13층, 패스트캠퍼스 신촌 강의장.
- 신촌역 3번 출구 도보 1분. 주차 미지원. 개인 노트북 지참.
- 점심 겸용 도시락 1인 1개와 간식 제공.

| 시간 | 공식 메일 내용 |
|---|---|
| 09:00–09:30 | 집결·정비 |
| 09:30–10:30 | 온보딩 |
| 10:30–17:30 | 해커톤 진행: 7시간 |
| 17:30–18:30 | 프로젝트 피칭·심사 |
| 18:30–19:00 | 시상식 |

메일에 팀별 피칭 시간은 없다. 1시간을 한 팀의 발표 시간으로 해석하지 않는다. 별도로 2026-10-06 사용자가 팀별 발표는 **5분**이라고 확인했다. 발표 준비는 이 길이를 기준으로 하며, 질의응답 포함 여부는 아직 확인하지 않았다.

## 공개 자료와 구분

[공식 행사 페이지](https://fastcampus.co.kr/NVIDIA_hackathon)는 목표에 따른 계획·도구 호출·문제 해결과 산업 문제를 강조한다. 2026-10-03 본문을 재확인했다. 공개 안내는 상위 5팀 쇼케이스를 설명하지만 상세 배점은 확인하지 못했다. 10월 3일 추가 조사에서도 신청 폼 원문은 HTTP 401로 확보하지 못했으며, 공식 배점이 공개된 적 없다고 단정하지 않는다.

새 미션은 당일 제공된다는 사용자 설명을 준비 전제로 한다. 10팀 진출도 사용자가 확인한 사실이며 팀 명단/선정 평가는 제공되지 않았다.

예선 저장소의 [9월 22일 기록](https://github.com/taehyunan-99/nvidia-hackathon/blob/52f6be29e432b1fa660e2a9b3b6b7556d04793d4/docs/hackathon/requirements.md)에는 L40S 1대·최대 1,000달러 Brev 크레딧 안내가 있다. **이번 메일에는 자원 지급 내용이 없으므로 실제 계정·가용량·지급 시점은 미확정**이다. 이를 지출 허가나 무제한 무료 API로 해석하지 않는다.

## 온보딩에서 기록할 질문

| 조건 | 현재 상태 | 구현에 미치는 영향 |
|---|---|---|
| 심사 항목·배점·필수 NVIDIA 기술 | 미공지 | 내부 루브릭 가중치 조정, 필수 경로 먼저 구현 |
| 사전 코드·스킬·템플릿 반입/재사용 | 미공지 | 준비물은 학습·리허설에 사용하고 본선 산출물 사용은 규정에 맞춤 |
| 외부 LLM·검색 API·인터넷 | 미공지 | 대체 endpoint와 검색 범위 결정 |
| GPU·Brev 크레딧·모델 키·쿼터 | 미공지 | hosted 우선 여부, GPU 배치·동시성 결정 |
| 제출물·마감 시각·공개 범위·발표 질의응답 | 미공지; 팀별 발표 5분은 2026-10-06 사용자 확인 | 제출 조건과 질의응답 포함 여부 확인 |
| 팀원 역할·사용 노트북 OS | 본선 2명(사용자+팀원) 확인, 상세 분담·OS 미정 | 두 사람의 환경 점검과 담당 배정 |

운영진 답변은 원문 또는 링크·확인 시각과 함께 이 표에 추가한다. 준비 자료의 자체 제안을 공식 규정으로 승격하지 않는다.
