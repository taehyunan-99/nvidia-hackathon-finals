# Physical AI / Isaac / Cosmos

물리 환경·로봇·영상 생성/시뮬레이션 미션 탐색

## 선택 조건

미션에 필요한 simulator/scene/센서/모델 가용성이 선행. 일괄 설치하지 않음.

## 바로 사용할 경로

1. [최소 실행 안내](../../playbooks/quickstarts/specialized.md)를 읽고 배치 경로를 선택한다.
2. 필요한 스킬만 아래 링크 또는 `python3 scripts/lookup.py --show tool:physical-ai`로 조회한다.
3. 준비된 작은 입력으로 실행하고 아래 성공 기준을 확인한다.

## 성공 기준과 실패 대안

- 성공 확인: 관련 샘플 scene·입출력·검증기를 먼저 확인.
- 축소/대안: 장비/scene 없이 현장 즉시 완료를 약속하지 않음; 해당 원문에서 feasibility 판단.
- 확인 수준: 공식 자료/스킬 조사. 본선 계정·실제 GPU/API 실행은 미검증.
