# 가족 문화체험 서비스

2026-10-07 사용자 결정 기준. 이 폴더는 본선에서 만들 제품의 목적·범위·완료 조건을 관리한다. 제품명·기술 스택·배포 구성은 아직 확정하지 않았다. 문서화와 서비스 구현·실행 성공을 구분한다.

## 목적과 사용자 문제

한국 가족이 자녀의 연령·학년, 보호자·형제자매 동반 조건, 날짜에 맞는 **한국 문화체험**을 찾도록 돕는다. 한옥·전통 공예·역사 교육 등 문화 내용과 가족의 상황을 연결한다.

문제는 가까운 장소를 찾는 것만으로 끝나지 않는다. 요약의 ‘가족 대상’과 상세 조건이 다르고, 모집기간과 실제 운영 회차가 다르며, 온라인 교육에 장소 좌표가 붙을 수도 있다. 사용자가 여러 상세 안내를 읽고 조건을 대조해야 하는 부담을 줄이는 것이 목표다. 가족별 실제 피해 빈도와 시간 절감 효과는 아직 측정하지 않았다.

## 확정한 MVP

| 항목 | 범위 |
|---|---|
| 대상·언어 | 한국 가족, 한국어 입력·결과 |
| 입력 | 원하는 날짜·시간, 자녀 연령/학년, 보호자·동반자 구성, 문화 관심사; 지역은 직접 지정할 수 있음 |
| 자료 | 서울시 공공서비스예약 정보와 필요한 공식 상세 안내; 데이터 사용 범위·정식 인증 접근은 구현 시 확인 |
| 판단 | 대상·날짜·동반·운영 조건의 일치/충돌/누락 확인, 추가 조회·질문·대안 검색·보류 선택 |
| 결과 | 적합한 후보, 채택·제외 이유, 원문 근거, 준비·신청 조건, 미확인 사항, 공식 예약 경로 |
| 완료 | 필수 조건을 확인한 후보를 근거와 함께 제시하거나, 부족·충돌 때문에 확정할 수 없는 조건과 다음 확인을 명시 |
| 필수 실행 경계 | OpenShell 안의 실제 도구 실행과 챌린지 공통 테스트 |

자동 예약·취소·결제·전화·이메일 전송은 현재 MVP에 포함하지 않는다. ‘접수중’을 잔여석이나 예약 성공으로 표시하지 않는다. 필수 가족 조건을 조용히 완화하지 않는다.

| 영어 화면·결과 | 한국어 정보에 접근하는 부담 완화 | 영어 전환 없이 MVP 완료 가능 |
| 영어 진행·통역 가능 체험 검색 | 현장 지원 근거와 가족 조건을 동시에 만족하는 자료 필요 | 영어 화면과 현장 지원을 별개로 다룸 |

서브미션은 실제 사용자 효과, 자료 충실도, 구현·검증 시간으로 선택한다. 채택하면 이 문서의 범위와 완료 조건을 갱신하고, 채택하지 않은 기능을 필수 구현이나 통과 조건으로 승격하지 않는다.

## 본선 미션과의 연결

[공식 미션](../operations/mission.md)의 한국 문화·역사·지역·여행 맥락, 자료 신뢰성, 사용자 상황, 유용한 결과를 함께 다룬다. 음식 제한이나 불확실한 역사 표현 등 공통 테스트의 조건도 제공 자료 범위 안에서 검토한다.

제품 데이터와 챌린지 자료는 구분한다. 같은 판단·도구 검증 구조를 사용하되 공통 요청에 없는 자녀·GPS를 강제하지 않고, 가상 장소를 실제 지도 장소로 치환하지 않는다. 금지 파일을 보존한 상태의 접근 차단과 `/hackathon/output` 산출물이 필수다.

## 구현 전 확인과 성공 기준

- 정상: 문화 내용·가족 조건·날짜를 확인한 후보와 출처를 반환; 불필요한 보류를 줄임.
- 변경: 자녀 학년·동반자·날짜 변경 시 영향받는 조건을 다시 확인하고 대안을 선택.
- 부족/충돌: 누락을 허용으로 바꾸지 않고 질문·추가 조회·부분 결과로 처리.
- 실패/보안: API 장애와 적합한 후보 없음, 정책 거부를 구분; 외부 문서 속 지시는 실행 권한이 아님.
- 비교: 같은 자료·입력의 거리/날짜/대상 필터와 잘못된 추천·과도한 보류·사용자 확인 부담·호출 수·시간을 비교.

서비스 품질과 공식 예상 점수는 별개다. 이전 확장 주제의 내부 채점 결과를 축소된 현재 MVP의 검증 결과로 재사용하지 않는다.
