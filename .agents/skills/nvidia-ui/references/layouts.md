# 요소 비교와 조합

사용자 요청에 따라 미세 비교를 종료하고 디자인 준비를 확정했다. 기존 선택은 `docs/design/design-decisions.json`의 decisions, 적용값은 assets/tokens.css를 따른다.

- 새 선택은 실제 사용을 막는 중요한 문제에 한정한다. 같은 내용에서 관련 속성만 비교하고 공식·예선 근거와 추천을 함께 설명한다.
- 이미 정한 버튼·입력창·카드·표를 대표 서비스 화면에 조합한다. 한 속성을 골랐다고 다른 요소까지 자동 확정하지 않는다.
- 진행·완료·보류·실패·빈 화면은 확정한 상태 묶음을 재사용한다. 대표 화면의 조작은 디자인·동작 확인용이며 실제 실행 결과가 아니다.
- 미정 장식값은 기존 임시값을 사용하되 확정된 것으로 표시하지 않는다. 구현에 지장이 없는 색·간격·레이아웃 취향을 다시 하나씩 묻지 않는다.
- 공식 마케팅 페이지와 실제 업무 화면의 목적이 다르면 가독성·근거 확인·작업 밀도를 고려한다. 캐러셀·표·폼의 예시를 모든 컴포넌트에 일반화하지 않는다.
