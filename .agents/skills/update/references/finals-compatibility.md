# 본선 저장소의 기존 가이드 형식

이 저장소는 사용자가 선택한 **7섹션 AGENTS.md/CLAUDE.md 동일 본문 + 양방향 hook**을 유지한다. 예선의 8섹션·CLAUDE import·별도 LEARNED_CAUTIONS 방식으로 자동 전환하지 않는다.

- 새 영역도 기존 7섹션을 따른다. COMMANDS는 HOW의 검증 명령에 포함한다.
- 실제 학습 기록은 기존 가이드의 7번 LEARNED CAUTIONS다. 별도 파일을 필수 전제로 삼지 않는다.
- learn의 현재 본체가 우선이며 두 가이드의 같은 학습 내용을 보존한다. 사용자 명시 호출 없이 기록하지 않는다.
- 본문을 수정하면 두 파일을 일치시키고 scripts/guide-pairs.json을 갱신한다. sync script/hook을 legacy라는 이유로 제거하지 않는다.
- 원본 update 참고문서의 8섹션/별도 파일 언급은 위 대응으로 해석한다. 학습 기록·사용자 결정 보존과 인터뷰/충돌 해소 절차는 유지한다.
- 새로운 가이드 정책으로 전환하려면 사용자의 별도 구조 변경 요청이 필요하다.
