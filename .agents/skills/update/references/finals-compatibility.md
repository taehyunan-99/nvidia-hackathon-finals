# 본선 저장소의 가이드 형식

<!-- prev: 7섹션 AGENTS/CLAUDE 동일 본문·양방향 hook → 2026-10-07 사용자 요청으로 AGENTS 원본·CLAUDE @ 참조로 전환. -->
이 저장소는 **7섹션 AGENTS.md 본문 + CLAUDE.md의 `@./AGENTS.md` 한 줄**을 사용한다. 본문 중복이나 8섹션/별도 학습 파일 방식으로 자동 전환하지 않는다.

- 새 영역도 기존 7섹션을 따른다. COMMANDS는 HOW의 검증 명령에 포함한다.
- 실제 학습 기록은 AGENTS.md의 7번 LEARNED CAUTIONS다. 기존 별도 학습 파일이 있다면 그대로 보존하며, 새 파일을 필수로 만들지 않는다.
- 현재 learn 본체가 우선이다. 메모는 원본에만 누적하고 CLAUDE import는 변경하지 않는다. 사용자 명시 호출 없이 기록하지 않는다.
- 새 가이드 참조 쌍은 scripts/guide-pairs.json에 등록한다. helper/hook은 참조를 검사하고 learn 스킬 본체 사본만 기존 방식으로 동기화한다.
- 원본 update 참고문서의 8섹션/별도 파일 언급은 위 대응으로 해석한다. 현재 대화에서 이미 확정한 결정을 재질문하지 않고, 미정·충돌 항목만 영역별 인터뷰한다.
- 사용자 결정·학습 기록 보존과 교차 충돌 해소 절차는 유지한다. 번들 assets의 범용 both 예시는 현행 저장소 규칙을 덮어쓰지 않는다.
