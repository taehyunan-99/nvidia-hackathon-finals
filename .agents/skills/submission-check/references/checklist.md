## F. 운영진 확인과 판정 유의점

- **Peer-review:** 총 10점과 자기 팀 투표 금지는 공식 안내에 따르되 PDF·슬랙·녹취의 순위 점수열/동점 처리 차이를 임의 계산하지 않는다. 준비 판정에는 미확인 질문으로 분리한다.
- **Private repo:** 구두 설명만을 모두에게 적용되는 자동 예외로 쓰지 않는다. C10에서 해당 팀의 협의·실제 접근을 확인한다.
- **공통 데이터:** TASK의 여행 코스는 연습 요청이다. 제품을 여행으로 제한하거나 제공 파일만 데이터로 쓰도록 강제하지 않는다.
- **출처 갱신:** 새로운 공지·repo revision이 있으면 실제 차이를 확인한다. 외부 조회 불가이면 기준 revision을 밝히고 최신이라고 주장하지 않는다. 매번 전체 PDF/녹취를 재추출하지 않는다.
- **고정 정답 없음:** 특정 출력 JSON·정답 문구·프레임워크·모델 학습·prover를 공식 필수로 추가하지 않는다. 문서상의 정책과 실제 동작의 일치가 중요하다.
